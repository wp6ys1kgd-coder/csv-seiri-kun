# CSV整理くん

初心者向けのCSV整理ツールです。現在の販売候補は、マクロなしで使えるExcel版です。

## Excel版 v2.0.0

- 入力シート：CSVの見出し・データを貼り付ける場所
- 整理結果シート：前後空白を整理し、重複候補を表示
- 操作説明シート：初心者向けの手順
- サンプルデータシート：動作確認用データ
- マクロなしの.xlsx形式

## 使い方

1. 元のCSVから見出しとデータをコピーします。
2. 「入力」シートへ貼り付けます。
3. 「整理結果」シートで結果を確認します。
4. 必要に応じてExcelの並べ替え、重複の削除を実行します。

## 制限

マクロなし構成のため、CSVファイルの直接読込、ボタンによる自動保存、完全自動の並べ替えは行いません。Excel 365を推奨します。
