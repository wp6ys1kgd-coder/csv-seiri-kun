# CSV整理くん

初心者向けのCSV整理ツールです。マクロなしで使えるExcel版を中心に、派生ツールを開発しています。

## Excel版 v2.0.0

- 入力シート：CSVの見出し・データを貼り付ける場所
- 整理結果シート：前後空白を整理し、重複候補を表示
- 操作説明シート：初心者向けの手順
- サンプルデータシート：動作確認用データ
- マクロなしの.xlsx形式

## CSV分割くん Excel版 v1.0.0

1ファイルあたりの行数を指定し、グループ番号と保存ファイル名を表示します。グループごとにデータをコピーしてCSV保存できます。

- 分割結果シート：グループ番号、保存ファイル名、分割データ
- 入力シート：CSV貼り付け欄
- 操作説明シート：初心者向け手順
- サンプルデータシート：7件のサンプル
- マクロなしの.xlsx形式

## 使い方

1. 元のCSVから見出しとデータをコピーします。
2. 対象ツールの「入力」シートへ貼り付けます。
3. 結果シートで整理または分割結果を確認します。
4. 必要に応じて値をコピーし、CSV形式で保存します。

## 制限

マクロなし構成のため、CSVファイルの直接読込、複数CSVの自動書き出し、ボタンによる自動保存には対応していません。Excel 365を推奨します。
