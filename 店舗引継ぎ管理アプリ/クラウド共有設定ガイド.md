# クラウド共有設定ガイド

フォルダ内の `クラウド共有.html` から設定します。クラウド共有は任意機能です。

## 手順

1. 接続先サービスでJSONを受け取るエンドポイントを作成
2. 接続先URLと必要なアクセストークンを入力
3. 保存時はPOSTまたはPUTを選択
4. 「クラウドへ保存」で送信
5. 別のPCでは同じ接続先を設定し「クラウドから読込」を実行

## 接続先の例

- SharePoint／Power Automate：HTTP要求を受け取るフローを作成し、SharePoint等へ保存
- Firebase：HTTPS Callable／RESTエンドポイントを用意
- Supabase：テーブルとRLSポリシーを設定し、REST URLを使用
- 汎用REST API：JSONの `data` 配列を受け取れるAPIを用意

## 注意

- サービス側の認証・権限設定は購入者自身で行ってください。
- 接続先URLとアクセストークンはブラウザのlocalStorageに保存されます。共有PCでは使用後に「設定を消去」してください。
- 実在データを送信する前に、架空データで保存・読込を確認してください。
- 実クラウド接続先との通信は販売前テストの対象外です。
