# 販売前テストチェックリスト

- `index.html` をChromeまたはEdgeで開ける
- 「サンプルデータを読み込む」で2件が表示される
- 新規登録後、ダッシュボードと一覧の件数が増える
- 一覧から行をクリックして編集できる
- 対応状況を「完了」にすると完了件数が増える
- 期限を過去日にすると期限超過として表示される
- キーワード検索と未対応・期限超過フィルターが動く
- 改善策を入力した完了案件が改善策一覧に表示される
- JSON保存とJSON復元でデータが戻る
- CSV保存ファイルを `CSV復元.html` で読み込める
- `月次集計.html` で対象月の件数を確認できる
- `印刷用テンプレート.html` で印刷プレビューを開ける
- 設定画面で保存件数を確認し、消去確認が表示される
- ブラウザを閉じて再度開いてもデータが残る
