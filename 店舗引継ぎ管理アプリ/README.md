# 店舗引継ぎ・申し送り管理Webアプリ

`index.html`をChromeまたはEdgeで開くだけで使える、サーバー不要の業務アプリ試作です。データはブラウザのlocalStorageに保存されます。

対応：ダッシュボード、新規登録、一覧、編集・削除、状況管理、期限超過判定、検索、改善策一覧、JSON/CSV保存、JSON/CSV復元、月次集計、印刷用テンプレート、架空サンプルデータ。

補助画面として `月次集計.html`、`CSV復元.html`、`印刷用テンプレート.html` を同梱しています。いずれも同じブラウザの保存データを利用します。

案件詳細の「この案件を印刷」から印刷画面へ進みます。案件が指定されていない場合は印刷できず、先頭案件を勝手に表示しません。

登録済みデータがある場合、サンプル読込は既存データ保護のため停止します。JSONは全項目の保全用、CSVは一覧交換用です。

補助画面として月次集計、CSV復元、印刷、設定、バックアップ案内を同梱しています。ブラウザのデータ削除や別PCではデータが消えるため、定期的にバックアップしてください。

`クラウド共有.html`では、接続先URL・アクセストークン・POST／PUTを設定してJSONデータをクラウドへ保存・読込できます。利用するサービス側でJSONエンドポイントを用意してください。

設定方法とアクセストークンの取扱いは `クラウド共有設定ガイド.md` を確認してください。
