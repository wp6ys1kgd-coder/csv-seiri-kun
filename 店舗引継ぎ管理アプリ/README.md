# 店舗引継ぎ・申し送り管理Webアプリ

`index.html`をChromeまたはEdgeで開くだけで使える、サーバー不要の業務アプリ試作です。データはブラウザのlocalStorageに保存されます。

対応：ダッシュボード、新規登録、一覧、編集・削除、状況管理、期限超過判定、検索、改善策一覧、JSON/CSV保存、JSON復元、月次集計、印刷用テンプレート、架空サンプルデータ。

補助画面として `月次集計.html`、`CSV復元.html`、`印刷用テンプレート.html` を同梱しています。いずれも同じブラウザの保存データを利用します。

印刷対象を指定する場合は、`印刷用テンプレート.html?id=案件のid` の形式で開きます。指定がない場合は保存データの先頭案件を表示します。

補助画面として月次集計、CSV復元、印刷、設定、バックアップ案内を同梱しています。ブラウザのデータ削除や別PCではデータが消えるため、定期的にバックアップしてください。
