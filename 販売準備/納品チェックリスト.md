# 納品チェックリスト

## 要件確認

- [ ] 購入者のOSとブラウザーを確認した
- [ ] 匿名化された入力サンプルを受け取った
- [ ] 期待する出力サンプルを確認した
- [ ] 基本料金内／追加料金の範囲を合意した
- [ ] 完成条件と納期を文章で合意した

## 開発・テスト

- [ ] 通常データで処理できる
- [ ] 空のCSVで分かりやすいエラーが出る
- [ ] 空行と重複行が指定どおり処理される
- [ ] 日本語が文字化けしない
- [ ] 元のCSVが変更されない
- [ ] ダウンロードを複数回行っても問題が起きない
- [ ] 購入者のサンプルで期待結果と一致する
- [ ] HTMLをChromeとEdgeで開ける
- [ ] 通信機能や外部参照が含まれていない

## 納品

- [ ] HTML、操作説明書、サンプルCSVをZIPにまとめた
- [ ] ファイル名とバージョンを確認した
- [ ] 操作手順と注意事項を納品メッセージに記載した
- [ ] 修正受付の期限と範囲を伝えた

## 実績化

- [ ] 公開してよい感想・評価を確認した
- [ ] 顧客情報を除いた画面画像を保存した
- [ ] 今回追加した機能を商品改善メモに記録した
