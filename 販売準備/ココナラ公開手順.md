# ココナラ公開手順

## 1. 出品形式

- 出品形式：通常サービス
- カテゴリ候補：IT相談・システム開発 → 業務自動化・効率化支援 → その他（業務自動化・効率化）
- 基本価格：3,000円
- 納期目安：必要情報の受領後3～5日

カテゴリ名は出品時の画面で最新の表示を確認し、最も近いものを選びます。

## 2. タイトルとキャッチコピー

タイトル：

> 毎週のCSV整理作業を1クリックで自動化します

キャッチコピー：

> 空行・重複削除・並べ替えをオフラインツールにします

詳しい本文は `ココナラ出品文.md` から貼り付けます。

## 3. サービス画像

次の順番で登録します。

1. `出品画像/01_表紙.png`
2. `出品画像/02_読み込み画面.png`
3. `出品画像/03_整理完了画面.png`

## 4. プロフィール文案

> 手作業で繰り返している小さな事務作業を、初心者でも使いやすいツールにするお手伝いをしています。現在はCSVの空行・重複削除、並べ替えなど、範囲を明確にした小規模な自動化を中心に対応しています。実際の個人情報は受け取らず、匿名化したサンプルデータで制作・確認します。ご相談内容を確認し、対応範囲と完成条件を整理してから制作します。

資格や業務実績など、確認できていない内容は追記しません。

## 5. 最初の問い合わせへの返信案

> お問い合わせありがとうございます。対応可否を確認するため、実際の情報を架空の内容へ置き換えたサンプルCSVと、現在手作業で行っている手順をお送りいただけますでしょうか。あわせて「どの状態になれば完成か」が分かる整理後の例があると、より正確に確認できます。内容を拝見したうえで、基本料金内で対応できるか、納期とともにご案内します。

送信前に、`購入前ヒアリング票.md` と照らし合わせます。

## 6. 公開直前の確認

- [ ] タイトル・説明・料金が一致している
- [ ] 対応外の内容を明記している
- [ ] 「CSVは外部送信されない」と実装が一致している
- [ ] 実績、資格、効果を誇張していない
- [ ] 画像3枚を正しい順番で登録した
- [ ] 購入前のお願いに匿名化サンプルの説明がある
- [ ] 通知を受け取れる状態になっている

公開後は、公開日を `AIチーム/案件管理.csv` に記録します。
