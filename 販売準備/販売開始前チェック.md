# 販売開始前チェック（オフラインHTML版）

## 現在の確認状況

- [x] EXEを使わないオフラインHTML版へ切り替え
- [x] CSV解析・空行削除・重複削除・並べ替えのテスト4件が合格
- [x] HTML内にCSSとJavaScriptを統合し、外部ファイル参照がない
- [x] 操作説明書とサンプルCSVを含む配布ZIPを作成
- [ ] ChromeでサンプルCSVの読み込みから保存まで手動操作
- [x] Edgeで読み込み状態と整理完了状態を描画確認
- [x] 出品用の実画面画像を3枚用意

## 切り替えの理由

開発PCのSmart App Controlが未署名EXEをブロックしたため、配布形式をオフラインHTMLへ変更した。HTML版は実行ファイルではなく、ChromeまたはEdgeで開いて使用する。CSV処理は端末のブラウザー内だけで行い、外部送信しない。

## 販売前の判断

ChromeとEdgeで手動確認できた場合：

1. 入力、ダウンロード、エラー表示を確認する。
2. 顧客情報を含まない実画面画像を撮影する。
3. 配布ZIPを最終確認する。
4. 商品ページを公開する。

ブラウザーごとの差異が見つかった場合は、再現条件を記録して修正し、テスト項目へ追加する。
