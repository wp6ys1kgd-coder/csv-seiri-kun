# 設備・車両・備品 点検期限管理Webアプリ

`index.html`をChromeまたはEdgeで開くだけで使える、サーバー不要・オフライン対応の期限管理アプリです。データはブラウザのlocalStorageに保存されます。

## 起動

フォルダ内の`index.html`をダブルクリックしてください。最初は「サンプルデータを読み込む」で架空データを表示できます。

初回起動時は、サンプルデータで開始するか、空の状態で開始するかを選択できます。

## 主な機能

- 対象登録、編集、削除、期限の自動計算
- 正常／30日以内／14日以内／7日以内／本日期限／期限超過の判定
- 点検完了と履歴蓄積、次回期限更新
- 管理一覧、月次予定、履歴、集計、検索・絞り込み
- UTF-8 BOM付きCSV出力・読込（追加／置換）
- JSONバックアップ・復元、印刷用データ確認
- 設定画面で事業所名、担当者一覧、分類一覧、期限警告日数を保存

販売前テストの詳細は `販売前テスト結果.md` を参照してください。Chrome実機確認など未確認項目も記載しています。

## 注意

ブラウザごとにデータが保存されます。PC変更やブラウザデータ削除に備え、定期的にJSONバックアップを保存してください。サンプルはすべて架空情報です。
